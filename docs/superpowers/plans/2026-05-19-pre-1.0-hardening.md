# Pre-1.0 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the project-engineering work needed to cut a credible 1.0: lint/type/format toolchain, single-sourced versioning + PyPI release automation, parallel rendering, structured logging, coverage and security gates in CI, macOS coverage, and a showcase regression guard.

**Architecture:** Thirteen narrowly-scoped tasks, each landing in its own commit (or small series). Tasks are independent enough to be reordered, but the listed order minimizes rework (lint/format first so the new code lands clean; version single-sourcing before release workflow; etc.).

**Tech Stack:** Python 3.10–3.12, `ruff`, `mypy` (gradual), `pre-commit`, `pytest-cov`, `concurrent.futures`, `logging` stdlib, GitHub Actions (`pypa/gh-action-pypi-publish` via OIDC, Dependabot, `pypa/gh-action-pip-audit`).

**Scope decisions locked in (from brainstorming):**
- mypy mode: **gradual** — `src/airflow_diff/` only, allow untyped Airflow imports, no `--strict`.
- PyPI auth: **trusted publishing / OIDC** — no long-lived secrets. Requires one-time PyPI-side setup.
- Renderer parallelism: **ThreadPoolExecutor** — each renderer is already a subprocess; threads just block on `Popen.communicate`.
- Coverage floor: **80%** — measured on unit tests only, with `renderer.py` excluded (integration-only).

name: release
on:
  push:
    tags:
      - "v*"

jobs:
  verify-version:
    runs-on: ubuntu-latest
    outputs:
      version: ${{ steps.extract.outputs.version }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - id: extract
        name: Extract version from tag and verify it matches __version__
        run: |
          TAG_VERSION="${GITHUB_REF_NAME#v}"
          PKG_VERSION="$(python -c 'import sys; sys.path.insert(0, "src"); import airflow_diff; print(airflow_diff.__version__)')"
          echo "tag=$TAG_VERSION pkg=$PKG_VERSION"
          if [ "$TAG_VERSION" != "$PKG_VERSION" ]; then
            echo "::error::Tag $TAG_VERSION does not match airflow_diff.__version__ ($PKG_VERSION). Bump __version__ before tagging."
            exit 1
          fi
          echo "version=$TAG_VERSION" >> "$GITHUB_OUTPUT"

  build:
    needs: verify-version
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pipx install uv
      - run: uv pip install --system build
      - run: python -m build
      - uses: actions/upload-artifact@v4
        with:
          name: dist
          path: dist/

  publish:
    needs: [verify-version, build]
    runs-on: ubuntu-latest
    environment: pypi
    permissions:
      id-token: write  # required for trusted publishing
    steps:
      - uses: actions/download-artifact@v4
        with:
          name: dist
          path: dist/
      - uses: pypa/gh-action-pypi-publish@release/v1

  bump-action-default:
    needs: [verify-version, publish]
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
    steps:
      - uses: actions/checkout@v4
        with:
          ref: main
          token: ${{ secrets.GITHUB_TOKEN }}
      - name: Update action.yml default to match newly published version
        env:
          VERSION: ${{ needs.verify-version.outputs.version }}
        run: |
          python - <<'PY'
          import os, re, pathlib
          version = os.environ["VERSION"]
          p = pathlib.Path("action/action.yml")
          s = p.read_text()
          new = re.sub(
              r'(airflow-diff-version:\s*\n\s+description:[^\n]*\n\s+required:[^\n]*\n\s+default:\s*)"[^"]+"',
              lambda m: f'{m.group(1)}"{version}"',
              s,
          )
          assert new != s, "action.yml default not updated — regex did not match"
          p.write_text(new)
          PY
      - name: Open PR to bump action default
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          BRANCH="release/bump-action-${{ needs.verify-version.outputs.version }}"
          git config user.name "github-actions[bot]"
          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
          git checkout -b "$BRANCH"
          git add action/action.yml
          git commit -m "chore(action): bump default airflow-diff-version to ${{ needs.verify-version.outputs.version }}"
          git push -u origin "$BRANCH"
          gh pr create --title "chore(action): bump default to v${{ needs.verify-version.outputs.version }}" \

from airflow_diff.schema import RenderedDagBag


def _make_empty_bag(sha: str) -> RenderedDagBag:
    return RenderedDagBag.model_validate({
        "schema_version": 2,
        "commit_sha": sha,
        "airflow_version": "2.10.3",
        "rendered_at": "2026-05-19T00:00:00+00:00",
        "dags": [],
    })


def test_renderers_run_in_parallel(tmp_path, monkeypatch):
    """Two _spawn_renderer calls that each sleep for 0.5s should finish in <0.9s wall time."""
    sleep_for = 0.5
    spawn_started = threading.Event()
    spawn_in_flight = [0]
    spawn_in_flight_lock = threading.Lock()
    max_concurrent = [0]

    def fake_spawn(python, worktree, sha, config, fixtures_yaml):
        with spawn_in_flight_lock:
            spawn_in_flight[0] += 1
            max_concurrent[0] = max(max_concurrent[0], spawn_in_flight[0])
        spawn_started.set()
        time.sleep(sleep_for)
        with spawn_in_flight_lock:
            spawn_in_flight[0] -= 1
        return _make_empty_bag(sha)

    monkeypatch.setattr("airflow_diff.orchestrator._spawn_renderer", fake_spawn)
    monkeypatch.setattr("airflow_diff.orchestrator.resolve_sha", lambda repo, ref: f"sha_{ref}")
    monkeypatch.setattr("airflow_diff.orchestrator.ensure_sha_present", lambda repo, sha: None)
    monkeypatch.setattr("airflow_diff.orchestrator._touched_files", lambda *a, **kw: [])

    class _DummyCM:
        def __init__(self, p): self.p = p
        def __enter__(self): return self.p
        def __exit__(self, *a): return False

    monkeypatch.setattr(
        "airflow_diff.orchestrator.worktree_for",
        lambda repo, sha: _DummyCM(tmp_path / sha),

    for sha in ("sha_base", "sha_head"):

    config = Config()
    t0 = time.monotonic()
    run_diff(tmp_path, "base", "head", config)
    elapsed = time.monotonic() - t0

    assert max_concurrent[0] == 2, (
        f"expected both renderers in flight concurrently, peak was {max_concurrent[0]}"

def run_diff(repo_root: Path, base_ref: str, head_ref: str, config: Config) -> DiffDocument:
    from concurrent.futures import ThreadPoolExecutor

    base_sha = resolve_sha(repo_root, base_ref)
    head_sha = resolve_sha(repo_root, head_ref)
    ensure_sha_present(repo_root, base_sha)
    ensure_sha_present(repo_root, head_sha)

    touched = _touched_files(repo_root, base_sha, head_sha)

    with worktree_for(repo_root, base_sha) as wt_base, \
         worktree_for(repo_root, head_sha) as wt_head:

        fixtures_base = wt_base / config.fixtures_path
        fixtures_head = wt_head / config.fixtures_path

        def _render_side(wt: Path, sha: str, fixtures: Path) -> RenderedDagBag:
            py = venv_for(wt)
            return _spawn_renderer(
                py, wt, sha, config,
                fixtures if fixtures.exists() else None,
            )

        with ThreadPoolExecutor(max_workers=2, thread_name_prefix="airflow-diff-render") as ex:
            fut_base = ex.submit(_render_side, wt_base, base_sha, fixtures_base)
            fut_head = ex.submit(_render_side, wt_head, head_sha, fixtures_head)
            rendered_base = fut_base.result()
            rendered_head = fut_head.result()

    diff = compute_diff(rendered_base, rendered_head, touched_files=touched)
    diff.sensor_mismatches = _validate_cross_dag(rendered_base, rendered_head, config)
    return diff
```

def _configure_logging(verbose: int | bool, quiet: bool) -> None:
    """Configure the `airflow_diff` logger. Higher verbose → more output; quiet wins ties."""
    if quiet:
        level = logging.ERROR
    elif int(verbose) >= 2:
        level = logging.DEBUG
    elif int(verbose) >= 1:
        level = logging.INFO
    else:
        level = logging.WARNING
    logger = logging.getLogger("airflow_diff")
    logger.setLevel(level)
    # Avoid duplicate handlers when called repeatedly (tests, multiple CLI invocations).
    if not any(isinstance(h, logging.StreamHandler) for h in logger.handlers):
        handler = logging.StreamHandler()
        handler.setFormatter(logging.Formatter("%(levelname)s %(name)s: %(message)s"))
        logger.addHandler(handler)
        logger.propagate = False

"""Re-run each showcase case and assert the rendered markdown matches the checked-in output.

Marked `integration` because it imports Airflow indirectly via the renderer subprocess.
"""
from __future__ import annotations

import subprocess
from pathlib import Path

import pytest

REPO_ROOT = Path(__file__).resolve().parents[2]
SHOWCASE = REPO_ROOT / "examples" / "showcase"
EXPECTED_DIR = REPO_ROOT / "docs" / "showcase"


@pytest.mark.integration
@pytest.mark.parametrize("case", ["case-1", "case-2", "case-3"])
def test_showcase_output_matches(case: str):
    result = subprocess.run(
        ["bash", str(SHOWCASE / "make_history.sh"), case, "--run"],
        capture_output=True, text=True, cwd=str(SHOWCASE),
    )
    # case-1 produces a regression (exit 1); make_history.sh wraps with `|| true`,
    # so the script itself should exit 0 regardless.
    assert result.returncode == 0, (
        f"make_history.sh {case} failed:\nstdout:\n{result.stdout}\nstderr:\n{result.stderr}"
    )

    expected = (EXPECTED_DIR / f"{case}-output.md").read_text()
    # The script prints preamble before "--- airflow-diff output ---" — extract the markdown.
    marker = "--- airflow-diff output ---"
    assert marker in result.stdout, f"missing marker in output for {case}"
    actual = result.stdout.split(marker, 1)[1].strip()

    # Compare with normalized line endings; the checked-in file has its own preamble
    # that we want to match byte-for-byte once SHAs are deterministic.
    assert actual == expected.strip(), (
        f"showcase output for {case} drifted.\n"
        f"--- expected ({EXPECTED_DIR / f'{case}-output.md'}) ---\n{expected}\n"
        f"--- actual ---\n{actual}\n"
    )
```

(If the checked-in `docs/showcase/*-output.md` files contain extra preamble like "What `airflow-diff` posts on the PR" markdown wrapping, adjust `expected.strip()` and the marker extraction to compare only the airflow-diff body. Inspect one of the files before finalizing this test.)
